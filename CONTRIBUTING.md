# Contributing to AI News Agent

Thanks for your interest! This project is open source under the MIT license and welcomes all contributions.

## Quick Start

1. **Fork** the repository
2. **Clone** your fork: `git clone https://github.com/YOUR_USERNAME/ai-news-agent.git`
3. **Install** in dev mode: `pip install -e ".[dev]"`
4. **Create a branch**: `git checkout -b feature/your-feature`
5. **Test**: `python -m pytest tests/`

## Guidelines

- **Code style**: Follow PEP 8, line length 120
- **Tests**: Add tests for new features
- **Feeds**: When adding feeds, include `name`, `url`, `category`, and `tier`
- **No secrets**: Never commit API keys, tokens, or personal info
- **License**: By contributing, you agree your code is MIT licensed with attribution to AI Consy

## Reporting Issues

- Bug reports: Open a GitHub Issue with steps to reproduce
- Feature requests: Open a GitHub Issue with the `enhancement` label
- Security issues: Please DM via GitHub rather than filing a public issue
